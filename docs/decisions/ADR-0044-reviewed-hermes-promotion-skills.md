# ADR-0044: Seed a small reviewed organic promotion skill pack

Status: Accepted

Date: 2026-11-11

## Context

Hermes needs useful product research, creative planning and measurement
procedures. Importing a broad marketing collection could add irrelevant tools,
paid dependencies, unreviewed execution and misleading sending authority. The
owner has requested organic preparation with no paid spend and has separately
stopped creator mailing.

## Decision

Package eight concise reviewed skills in the existing pinned Hermes runtime's
`hermes-promotion` namespace. Adapt selected MIT-licensed upstream planning
patterns with exact commit provenance and notices; defer broad role collections
and packages whose relevant licenses were not reviewed. See the
[selection record](../../services/hermes/skills/PROVENANCE.md).

The existing networkless config initializer verifies a bounded manifest and file
digests before installing only its owned namespace into the private named
volume. It rejects unsafe paths, symlinks, tampering and collisions; staged
replacement retains rollback and preserves unrelated private skills and memory.
No skill is executed as code during installation.

Skills produce briefs, concepts, source reviews and experiment/release plans.
They grant no tools, accounts, scheduling, publication, SMTP or contact authority.
The current owner stop and all named contact holds override use of a skill.
Model output is a draft, not proof of product performance or compliance.

## Consequences

The pack adds no provider dependency, paid integration, broad host mount or new
service. Model use still consumes its configured compute/tokens. Installation
verification establishes packaging, not runtime discovery, a successful model
response, growth or virality. Live seeding and an actual planning canary remain
separate operating checks and must not restart sending workers.
