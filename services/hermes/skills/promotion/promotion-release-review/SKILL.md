# Promotion release review

Return a private readiness decision. This skill grants no email, publishing,
account, spending or scheduling authority. Only the owner can release an owner
hold; a restart, skill installation, old packet or general request for promotion
does not authorize mailing again. Preserve named contact holds and draft-only
restrictions even when another campaign resumes.

Review the full exact artifact, destination, intended audience, source evidence,
rights, relationship disclosure, link and measurement plan. Verify that every
feature claim is supported and every proposal remains labeled. Do not describe
cross-server rewards/currency as approved until current Minecraft rules and the
actual product architecture have been checked; unresolved fit blocks that claim.

Check the destination's current rules and the specific permission to publish.
Keep community moderation approval, creator agreement and owner approval
separate. Do not imitate independent player enthusiasm, hide sponsorships,
invent social proof, buy engagement or change the saved offer to make copy pass.

For email, the existing audited control-plane path remains mandatory: qualified
business identity, suppression/conversation checks, complete reply review,
current successful same-mailbox monitoring, source-bound draft, exact digest,
sender/footer and a reserved slot inside the original approval expiry. No bulk
template authority, arbitrary provider call, deadline extension, packet clone or
rate-limit increase follows from this review.

Return one of: blocked (specific unresolved hold/evidence/rights), draft-ready
(complete artifact awaiting the actual external authorization), or already
observed (dated evidence of the external result). List exact remaining decisions
without asking to clear old commercial replies merely to resume mail. Keep
draft completion, queueing, SMTP acceptance, publication and collaboration distinct.
