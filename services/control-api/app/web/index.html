Email setup

Connect your SMTP provider

Use the secure local setup prompt from the repository terminal:

./scripts/promotion.ps1 -ConfigureSMTP

Credentials stay in local configuration. Restart with the setup helper so workers load the settings, then check the connection here.

The check opens a connection and tests TLS, login and NOOP as configured. It sends no email. An owned-inbox test is a separate exact action; SMTP acceptance alone does not confirm inbox delivery.
